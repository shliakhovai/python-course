# Домашнє завдання

## Технічне завдання: Повторення базових концепцій Python

## Мета

Повторити роботу зі списками та рядками без застосування зовнішніх бібліотек:

- генератори списків (list comprehension), зокрема з умовою фільтрації та з умовним виразом;
- підрахунок кількості елементів за допомогою `len(...)`;
- базові операції над списками: підсумовування, пошук мінімуму та максимуму, обчислення середнього, вибірка унікальних значень.

Кожне завдання оформлюється у вигляді окремої функції із зазначеною сигнатурою. Використання циклів `for`/`while` для завдань 1–4 не передбачене — очікується розв'язання через генератори списків.

## Завдання

### 1. `only_even(numbers: list[int]) -> list[int]`

Повертає новий список, що містить лише парні числа з вхідного списку, зі збереженням порядку.

```python
only_even([1, 2, 3, 4, 5, 6])  # [2, 4, 6]
only_even([1, 3, 5])           # []
```

### 2. `squares(numbers: list[int]) -> list[int]`

Повертає список квадратів вхідних чисел.

```python
squares([1, 2, 3, 4])  # [1, 4, 9, 16]
```

### 3. `name_lengths(names: list[str]) -> list[int]`

Повертає список, у якому кожен елемент — довжина відповідного імені із вхідного списку (використати `len`).

```python
name_lengths(["Anna", "Bob", "Christopher"])  # [4, 3, 11]
```

### 4. `clamp_negatives(numbers: list[int]) -> list[int]`

Повертає список, у якому всі від'ємні числа замінені на `0`, а решта значень залишені без змін. Використати умовний вираз усередині генератора списку (`x if ... else ...`).

```python
clamp_negatives([-3, 5, -1, 0, 8])  # [0, 5, 0, 0, 8]
```

### 5. `count_long_words(words: list[str], min_length: int) -> int`

Повертає кількість слів, довжина яких **не менша** за `min_length`. Результат обчислюється як `len(...)` від відфільтрованого генератором списку.

```python
count_long_words(["cat", "elephant", "dog", "giraffe"], 4)  # 2
```

### 6. `count_vowels(text: str) -> int`

Повертає кількість голосних літер (`a, e, i, o, u`) у рядку `text` без урахування регістру.

```python
count_vowels("Hello World")  # 3
count_vowels("SKY")          # 0
```

### 7. `average(numbers: list[float]) -> float`

Повертає середнє арифметичне елементів списку (`sum(numbers) / len(numbers)`). Якщо список порожній — повернути `0.0`.

```python
average([2, 4, 6])  # 4.0
average([])         # 0.0
```

### 8. `min_max(numbers: list[int]) -> tuple[int, int]`

Повертає кортеж `(мінімум, максимум)` елементів списку. Гарантується, що список непорожній.

```python
min_max([7, 2, 9, 4])  # (2, 9)
```

### 9. `unique_sorted(items: list[int]) -> list[int]`

Повертає відсортований за зростанням список унікальних значень із вхідного списку.

```python
unique_sorted([3, 1, 2, 3, 1, 4])  # [1, 2, 3, 4]
```
