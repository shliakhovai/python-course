# Домашнє завдання

## Технічне завдання: учасники подій та редагування подій у Campus Pass API

## Мета

Розширити застосунок `campus_pass` ендпоінтами для роботи з учасниками подій та редагування самих подій.

## Завдання

### 1. `GET /api/events/{event_id}` — отримання однієї події

Повертає подію за `event_id`. `404`, якщо такої події не існує.

### 2. `POST /api/events/{event_id}/participants` — реєстрація учасника

Додає нового учасника (`ParticipantCreate`) до події за `event_id`. `404`, якщо події не існує; `409`, якщо вільних місць (`capacity`) вже немає. Відповідь — створений `Participant`, код `201`.

### 3. `GET /api/events/{event_id}/participants` — перегляд учасників

Повертає список учасників події. `404`, якщо події не існує.

### 4. `DELETE /api/events/{event_id}/participants/{participant_id}` — видалення учасника

Видаляє учасника з події. `404`, якщо не існує події або такого учасника в ній. Код відповіді — `204`.

### 5. `PATCH /api/events/{event_id}` — редагування події

Дозволяє частково оновити подію (будь-яке з полів `title`, `location`, `event_date`, `capacity`) через нову модель з необов'язковими полями. `404`, якщо події не існує; `409`, якщо нове `capacity` менше за поточну кількість учасників. Відповідь — оновлений `Event`, код `200`.

## Інструкція для студентів

- Дотримуйтесь стилю коду, що вже є в проєкті (`app/routers/events.py`, `app/routers/_detail/json.py`).
- Оформіть рішення у вигляді Pull Request і надайте посилання в особисті повідомлення.
