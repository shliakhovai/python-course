- модульні тести для звичайних функцій та класу;
- тести для FastAPI-ендпоінтів через `TestClient` — перевірка статус-коду, тіла відповіді (`json()`) та помилок.

## Підказка

Перевірка помилки, що виникає у функції, виконується через `pytest.raises`:

```python
import pytest
from logic import divide

def test_divide_by_zero():
    with pytest.raises(ValueError):
        divide(1, 0)
```

Для тестування FastAPI-застосунку використовується `TestClient`, що робить запити напряму до `app`, без реального сервера:

```python
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_get_books():
    response = client.get("/books")
    assert response.status_code == 200
```

## Завдання

### 1. Тести для `logic.py`

Файл `test_logic.py`. Необхідно перевірити:

- `add` — коректну суму для кількох пар чисел;
- `divide` — коректний результат ділення та виняток `ValueError` при діленні на нуль;
- `is_palindrome` — щонайменше по одному випадку для рядка-паліндрома та рядка, що ним не є;
- `Stack` — `push`/`pop` повертають елементи у правильному порядку (LIFO), `peek` не видаляє елемент, `is_empty` та `len()` коректно відображають стан, `pop`/`peek` на порожньому стеку викликають `IndexError`.

### 2. Тести для `main.py`

Файл `test_main.py`. Необхідно перевірити:

- `GET /books` — статус-код `200`, тіло відповіді є списком і містить очікувану кількість книг;
- `GET /books/{book_id}` — статус-код `200` та коректні дані для наявної книги; статус-код `404` для неіснуючого `book_id`;
- `POST /books` — статус-код `201`, тіло відповіді містить передані поля та згенерований `id`; після створення книга присутня у `GET /books`;
- `DELETE /books/{book_id}` — успішне видалення наявної книги; статус-код `404` для неіснуючого `book_id`.
